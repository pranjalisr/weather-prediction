# Weather Agent 🌦️🤖

A simple Python-based AI Weather Agent that fetches and provides real-time weather information using intelligent agent-based workflows.

This project demonstrates how an AI agent can process user queries, retrieve weather data, and generate meaningful responses using Python.

---

## ✨ Features

- 🌤️ Real-time weather information
- 🤖 AI agent-based architecture
- 🧠 Intelligent query handling
- ⚡ Lightweight and beginner-friendly
- 🐍 Pure Python implementation
- 📦 Modular code structure

---

## 🧠 How It Works

The project contains two main files:

`agent.py`

Handles the core weather agent logic:

Processes weather-related queries
Connects weather functionality
Generates responses

`main.py`

Entry point of the application:

- Starts the weather agent
Handles user interaction
Runs the application loop
🛠️ Tech Stack
Technology	Purpose
Python	Core programming language
AI Agent Logic	Query handling
Weather APIs	Fetch weather data
⚙️ Installation
1. Clone the repository
git clone https://github.com/pranjalisr/weather-prediction.git
cd weather-prediction
2. Create virtual environment
python -m venv venv

Activate it:

Windows
venv\Scripts\activate
macOS/Linux
source venv/bin/activate
3. Install dependencies
pip install -r requirements.txt

If requirements.txt is not available, manually install required packages.

▶️ Running the Project

Run the application using:

python py/weather_agent/main.py
